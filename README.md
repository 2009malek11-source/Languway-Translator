# Languway Translator — موقع ترجمة ثابت (PWA)

الرابط بعد النشر: https://2009malek11-source.github.io/Languway-Translator/
اسم الموقع: **Languway Translator** (الكلمة الثانية في الشعار تتبدّل حسب لغة الواجهة: مترجم / Translator / Traducteur / Traductor / Übersetzer / Çevirmen / Переводчик).

## النشر على GitHub Pages
1. افتح المستودع ← Add file ← Upload files، وارفع **كل** محتويات هذا المجلد (بما فيه مجلد `vendor`) مع استبدال الملفات القديمة.
2. من Settings ← Pages اختر الفرع `main` والمجلد `/ (root)`.
3. افتح الرابط وحدّث الصفحة مرة أو مرتين حتى يصل Service Worker الجديد.

## لغات واجهة الموقع
العربية، English، Français، Español، Deutsch، Türkçe، Русский — من القائمة في الشريط العلوي، وتُحفظ في المتصفح. كل لغة في ملف `i18n-<رمز>.js`، والنص المصدر عربي. لإضافة لغة: أضف ملفاً بالصيغة نفسها وسجّلها في `LANGS` داخل `i18n.js` وفي قائمة الملفات في `sw.js`.

## ما يعمل بلا أي مفاتيح (موقع ثابت بلا خادم)
| الميزة | الخدمة المستخدمة |
|---|---|
| الترجمة السريعة | MyMemory (حدّها اليومي مجاني ومحدود، ويظهر تنبيه واضح عند بلوغه) |
| الأساليب والمجالات والمساعد الذكي وقراءة الصور (OCR) وترجمة الملفات | Pollinations AI (مجاني، قد يتأخر أو يتوقف أحياناً) |
| القاموس والأمثلة | Free Dictionary وWiktionary وTatoeba |
| الإملاء والنطق | متصفحك (Web Speech API): Chrome / Edge / Safari |
| ملفات DOCX وPPTX وXLSX وPDF وTXT وMD وSRT | تُقرأ وتُبنى داخل المتصفح بمكتبتين محليتين (`vendor/jszip.min.js` و`vendor/pdf.min.mjs`) |

لا توجد مفاتيح API في الكود. النصوص والصور والملفات لا تُرسل لأي جهة غير الخدمات المذكورة أعلاه، والسجل والمفضلة والإعدادات تُحفظ في متصفح المستخدم فقط.

## ما لا يتوفر في نسخة بلا خادم
- حسابات المستخدمين وتزامن البيانات بين الأجهزة (البديل المتوفر: نسخة احتياطية من «الملف الشخصي»).
- ضمان توفر الخدمات المجانية أو سرعتها أو جودة ترجمتها.
- قراءة الصور الممسوحة أو الخط اليدوي بدقة عالية (تعتمد على نموذج الذكاء الاصطناعي المجاني).

## ملفات الموقع
`index.html` الصفحة · `style.css` التنسيق · `script.js` القاموس والإعدادات والتنقل · `translator.js` المترجم والصوت والمحادثة والمساعد · `media.js` الصور والمستندات · `app.js` النوافذ واللغات والملف الشخصي · `i18n.js` محرك لغة الواجهة · `i18n-*.js` قواميس اللغات · `sw.js` العمل بدون إنترنت.

لتفعيل زر «مراسلة بالبريد» في صفحة التواصل ضع بريدك في الثابت `CONTACT_EMAIL` أعلى ملف `app.js`.
