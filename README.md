# لسان — مترجم ومعلّم لغوي (PWA)

كل الملفات في مستوى واحد (بدون مجلدات) لتعمل مباشرة على GitHub Pages.

## النشر
1. ارفع كل الملفات إلى جذر المستودع.
2. فعّل GitHub Pages من Settings ← Pages.
3. افتح الرابط (HTTPS) وسيظهر زر التثبيت.

## ملاحظات
- ضع صورة رمز QR باسم `qr.png` بجانب `index.html` لتظهر في قسم التثبيت.
- الوضع الذكي اختياري: أدخل مفتاح Anthropic API في الإعدادات (يُحفظ على جهازك فقط).
- عند تعديل أي ملف غيّر `VERSION` في `sw.js` لتحديث الذاكرة المؤقتة.
