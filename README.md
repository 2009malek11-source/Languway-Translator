# مترجم Languway (PWA)

الرابط: https://2009malek11-source.github.io/Languway-Translator/

## الاستبدال على GitHub
1. افتح المستودع Languway-Translator ← Add file ← Upload files.
2. احذف الملفات القديمة كلها أولاً (حدّدها واحذفها) ثم ارفع **كل** ملفات هذا المجلد (كل الملفات) إلى الجذر مباشرة، بما فيها `.nojekyll`.
3. انتظر دقيقة حتى ينشر GitHub Pages، ثم افتح الرابط. يجب أن ترى v2.4 بجانب الاسم.
4. إن كنت ثبّتّ التطبيق سابقاً فاحذفه من الشاشة الرئيسية ثم ثبّته من جديد.

عند أي تعديل لاحق غيّر `VERSION` في `sw.js`.

## ما الجديد في v2.4
- مساحة كتابة كبيرة تتسع مع النص (حتى 5000 حرف) لترجمة مقال كامل، وتظهر النتيجة بجانبها على الشاشات الكبيرة.
- ميكروفون: الإملاء بالصوت ثم الترجمة مباشرة (Chrome / Edge / Safari؛ على بقية المتصفحات استخدم ميكروفون لوحة المفاتيح).
- كاميرا: التقاط صورة أو اختيارها من المعرض، يُقرأ نصها بالذكاء الاصطناعي ثم يُترجم.
- نطق النص الكامل، نسخ الترجمة، حفظها كملف نصي، واستخدامها كنص أصلي.
- إصلاح التمرير بعجلة الفأرة وباللمس (كان معطّلاً بسبب `overflow-x: hidden` على html وbody معاً).
- لا حسابات ولا تسجيل دخول: كل شيء محفوظ في متصفحك فقط.

### v2.4 — إعادة بناء الشرح الذكي
- عميل واحد للذكاء الاصطناعي (`ai`) بدل الدوال المتفرقة: طابور بفاصل 31 ثانية بين الطلبات (حد الخدمة المجانية)، وعند الرفض 402/429 ينتظر المدة التي تحددها الخدمة ويعيد مرة واحدة.
- ترجمة النصوص الطويلة عبر MyMemory فقط (لا تستهلك حصة الذكاء الاصطناعي).
- إن تعذّر الشرح الذكي يبقى شرح القواميس ويظهر زر «إعادة المحاولة».

### v2.5
- الميكروفون: يطلب الإذن صراحةً، ويعرض سبب الفشل (إذن مرفوض / لا يستجيب / غير مدعوم) ويدلّ على ميكروفون لوحة المفاتيح.
- الكاميرا: القراءة تتم داخل المتصفح بمحرك Tesseract (يُحمَّل من jsDelivr عند أول استخدام) بدل نموذج الذكاء الاصطناعي.
- الشرح الذكي: طلب واحد مختصر، يعرض سبب الفشل بوضوح، ويشرح «القاعدة: لماذا هذه الكلمة؟» ويعرّف الكلمة بالعربية وبلغتها وبلغة الترجمة.
- النصوص الطويلة: زر «اشرح القاعدة بالذكاء».

### v2.6

### v2.7

### v2.8

- ميزات جديدة: فتح ملف نصي (وسحبه)، شارات الإنجاز في لوحتي، تصدير CSV في المفضلة، اختبار «اكتب الإجابة»، نسخة احتياطية/استعادة وفحص التحديثات في الإعدادات.
